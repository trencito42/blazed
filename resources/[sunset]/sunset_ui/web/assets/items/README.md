# Inventory icon assets

This directory vendors the 100 x 100 WebP build of
[`SwisserDev/fivem-inventory-icons`](https://github.com/SwisserDev/fivem-inventory-icons),
version 1.0 (232 files).

The artwork is dedicated to the public domain under CC0 1.0. The complete
license notice is included as `LICENSE-CC0.txt`.

Sunset item definitions store the icon basename only. For example,
`icon = 'water_bottle'` resolves to `assets/items/water_bottle.webp` in NUI.
